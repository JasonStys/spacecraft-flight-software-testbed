    FIELD GUIDE

    Know what this lab proves.

    Getting started

    Choose a fault, run the experiment, then scrub the replay. Compare working data with committed checkpoints. Switch perspective to see why missing packets must not be interpreted as zero measurements.

    Faults & recovery

    A watchdog resets a hung executive. Stale sensors or a low synthetic power index enter latched SAFE mode. A corrupt checkpoint is rejected. The explicit resume at fault tick + 40 restores science only after health checks.

    Model boundaries

    Logical ticks are not seconds. This is not an RTOS, spacecraft dynamics model, cFS distribution, certified system, guidance tool or device controller. CRC detects accidental corruption, not malicious tampering. All data is invented.

    Privacy & portable app

    Runs stay on this PC. No account, analytics, cloud service or hardware connection. Only finite settings are saved in browser storage when available. Download the matching OS bundle from Releases; extract it and launch the executable. Builds are unsigned; don’t disable operating-system protections.
